# Lista bejárása elemenként (for … in lista)

## Mit jelent a bejárás?
A <b>bejárás</b> azt jelenti, hogy a lista minden elemét sorban, egyszer megvizsgáljuk. Szinte minden listás feladat bejárással kezdődik. A legegyszerűbb módja a <code>for elem in lista:</code> szerkezet: a ciklusváltozó minden körben a lista következő elemét kapja meg, a törzs pedig pontosan annyiszor fut le, ahány eleme van a listának.
```python
jegyek = [4, 5, 3, 5, 4]
for jegy in jegyek:
    print(jegy)
```

## A bejárás képen
A <code>for x in lista:</code> ciklus minden körben a lista <b>következő elemét</b> teszi az <code>x</code> változóba, az elsőtől az utolsóig. A kiemelt elem az, amelyik az adott körben az <code>x</code> értéke.
@abra bejaras

## Kiírás bejárás közben
Az elemeket egymás alá vagy egy sorba is kiírhatod, és számlálóval sorszámot is adhatsz nekik. A számláló kezdőértékét mindig a ciklus előtt kell megadni.
```python
nevek = ["Anna", "Bence", "Csilla"]
sorszam = 1
for nev in nevek:
    print(f"{sorszam}. {nev}")
    sorszam += 1

for nev in nevek:
    print(nev, end=" ")   # Anna Bence Csilla
```

## Válogatás bejárás közben
A ciklus törzsében elágazást is használhatsz, így csak a megfelelő elemekkel foglalkozol. A feltétel az aktuális elemre vonatkozik.
```python
jegyek = [4, 5, 3, 5, 2]
for jegy in jegyek:
    if jegy >= 4:
        print(jegy, "jó jegy")
```

## Számolás bejárás közben
Bejárás közben egy külön változóban gyűjthetsz is valamit, például összeget. Ez a gondolat adja majd a programozási tételek alapját, ezeket a következő témákban külön, tételenként tanuljuk meg.
```python
jegyek = [4, 5, 3, 5, 4]
osszeg = 0
for jegy in jegyek:
    osszeg += jegy
print(osszeg)   # 21
```

## Szövegek bejárása
A bejárás nem csak listákra működik. A szöveg karakterei is bejárhatók ugyanígy.
```python
for betu in "alma":
    print(betu)
```

## Gyakori tévedés
Bejárás közben a ciklusváltozó az elem <b>másolatát</b> kapja meg. Ha megváltoztatod, a lista nem változik. A lista elemeinek módosításához index kell, erről a következő témák szólnak.
```python
l = [1, 2, 3]
for x in l:
    x = x * 2
print(l)        # [1, 2, 3], a lista nem változott
```

## Összefoglalás
A for elem in lista a lista minden elemét sorban egyszer adja. Bejárás közben kiírhatunk, válogathatunk és gyűjthetünk értéket egy külön változóba. A ciklusváltozó módosítása nem változtatja a listát.
