# Elemek elérése indexszel

## Az index
A lista minden eleméhez tartozik egy sorszám, az <b>index</b>, amellyel az elemet közvetlenül elérheted. Az indexelés <b>0-tól indul</b>: az első elem indexe 0, a másodiké 1, és így tovább. Az elemet szögletes zárójellel kéred le: <code>lista[index]</code>.
```python
nevek = ["Anna", "Bence", "Csilla", "Dani"]
#          0        1         2        3
print(nevek[0])    # Anna
print(nevek[2])    # Csilla
```

## Negatív index
A negatív index hátulról számol: a <code>-1</code> az utolsó, a <code>-2</code> az utolsó előtti elem. Így az utolsó elemet akkor is elérheted, ha nem tudod, hány eleme van a listának.
```python
nevek = ["Anna", "Bence", "Csilla", "Dani"]
print(nevek[-1])   # Dani
print(nevek[-2])   # Csilla
```

## Indexek előre és hátra
Ugyanaz a lista kétféleképpen indexelhető: elölről <code>0</code>-tól, hátulról <code>-1</code>-től. Egy ötelemű listában a <code>lista[0]</code> és a <code>lista[-5]</code> ugyanaz az elem.

## Az érvényes indexek
Ha a listának <code>n</code> eleme van, az érvényes indexek 0-tól n-1-ig terjednek, a negatív indexek pedig -1-től -n-ig. Az utolsó elem indexe tehát <code>len(lista) - 1</code>, ez ugyanaz az elem, mint a <code>lista[-1]</code>.
```python
l = [10, 20, 30]
print(len(l))          # 3
print(l[len(l) - 1])   # 30
print(l[-1])           # 30
```

## Elem módosítása
A lista <b>módosítható</b>: egy elemét az index megadásával átírhatod, ez ugyanúgy értékadás, mint a változóknál. A bal oldalon áll a módosítandó elem, a jobb oldalon az új érték.
```python
nevek = ["Anna", "Bence", "Csilla"]
nevek[1] = "Balázs"
print(nevek)      # ["Anna", "Balázs", "Csilla"]

szamok = [4, 9, 2]
szamok[0] = szamok[1] + 1
print(szamok)     # [10, 9, 2]
```

## A tipikus hiba: IndexError
Ha olyan indexet adsz meg, amilyen elem nincs a listában, a Python <code>IndexError: list index out of range</code> hibát jelez. Ez azt jelenti, hogy az index kívül esik a lista határain. Leggyakoribb oka az, hogy a 0-tól indulást elfelejted, és az utolsó elem indexének a <code>len(lista)</code>-ot gondolod. Üres listának nincs egyetlen érvényes indexe sem.
```python
l = [1, 2, 3]
print(l[3])    # IndexError: az utolsó index 2

ures = []
print(ures[0]) # IndexError: nincs elem
```

## Összefoglalás
Az index 0-tól indul, a negatív index hátulról számol. Az érvényes indexek 0-tól len(lista) - 1-ig tartanak. Az elem a lista[index] alakkal kérhető le és írható át. Érvénytelen indexnél IndexError keletkezik.
