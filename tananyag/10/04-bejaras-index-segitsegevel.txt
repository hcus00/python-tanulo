# Lista bejárása indexekkel (range(len()))

## Mikor kell az index?
Az elemeket eddig közvetlenül, a <code>for elem in lista</code> alakkal jártuk be. Index viszont akkor kell, ha:
- módosítani szeretnéd a lista elemeit
- tudnod kell, hányadik helyen áll az elem
- az elem szomszédjára is szükséged van
- két listát együtt, azonos hely szerint kezelsz

## A range(len(lista)) szerkezet
Az index szerinti bejárás kulcsa: a <code>len(lista)</code> megadja az elemek számát, a <code>range(len(lista))</code> pedig pontosan az érvényes indexeket adja, 0-tól len-1-ig. A ciklusváltozó itt az <b>index</b>, az elemet a <code>lista[i]</code> adja.
```python
l = [4, 7, 9]
for i in range(len(l)):
    print(i, l[i])
# 0 4
# 1 7
# 2 9
```

## Elemek módosítása
Mivel az index segítségével az elem helye ismert, a lista elemei át is írhatók. Hasonlítsd ezt össze az előző témában látott másolattal: itt a lista tényleg megváltozik.
```python
l = [1, 2, 3]
for i in range(len(l)):
    l[i] = l[i] * 2
print(l)    # [2, 4, 6]
```

## Részleges és fordított bejárás
A <code>range</code> harmadik paramétere a lépésköz, így elég a minden második elemet bejárni, vagy akár visszafelé is haladhatsz.
```python
l = [10, 20, 30, 40, 50]
for i in range(0, len(l), 2):
    print(l[i])            # 10 30 50

for i in range(len(l) - 1, -1, -1):
    print(l[i])            # 50 40 30 20 10
```

## Szomszédos elemek
Ha egy elemet a következővel kell összevetni, az utolsó előtti indexig kell menni, különben a <code>l[i + 1]</code> a lista végén túlra mutatna.
```python
l = [5, 7, 9]
for i in range(len(l) - 1):
    print(l[i], "->", l[i + 1])
# 5 -> 7
# 7 -> 9
```

## Két lista együtt
Ha két lista azonos sorrendben tartozik össze (például nevek és jegyek), az azonos index köti össze az elempárokat.
```python
nevek = ["Anna", "Bence", "Csilla"]
jegyek = [5, 4, 3]
for i in range(len(nevek)):
    print(nevek[i], jegyek[i])
```

## Gyakori hibák és választás
Ezekre figyelj:
- <code>range(len(l) + 1)</code> egyel túlmegy a lista végén, ez IndexError
- a <code>l[i]</code> helyett az <code>i</code>-t írod ki, így az indexet kapod az elem helyett
- ha az indexre nincs szükséged, a <code>for elem in lista</code> egyszerűbb és biztonságosabb

## Összefoglalás
Az index szerinti bejárás alakja for i in range(len(l)), az elem l[i]. Ezzel módosíthatunk, szomszédokat és párhuzamos listákat kezelhetünk. Ha az indexre nincs szükség, elég a for elem in l.

### teszt
kerdes: Miért kell az index, ha a lista elemeit módosítani szeretnéd?
valaszok:
- mert a ciklusváltozó csak másolat, az index jelöli az átírandó helyet
- mert így gyorsabb a program
- mert a for elem in l nem működik számokkal
jo: 0
magyarazat: A másolat átírása nem változtatja a listát, az l[i] viszont az eredeti elemet éri el.
