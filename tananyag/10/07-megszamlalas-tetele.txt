# Megszámlálás tétele

## Mi a feladat?
A <b>megszámlálás</b> tétele azt kérdezi: hány olyan eleme van a sorozatnak, amely teljesít egy adott feltételt? Példák: hány ötös jegyet kaptál, hány páros szám van a listában, hány 18 évnél idősebb tanuló van az osztályban. A bemenet egy lista, a kimenet egy darabszám.

## Az algoritmus szavakkal
A megszámlálás is három lépésből áll:
- a darabszámot (számlálót) 0-ról indítjuk
- minden elemre megvizsgáljuk a feltételt, és ha teljesül, a számlálót eggyel növeljük
- a ciklus végén kiírjuk a számlálót

## A megszámlálás folyamatábrán
A lényeges különbség az összegzéshez képest a második rombusz: a számláló csak akkor nő, ha az elem megfelel a feltételnek. Ha nem felel meg, a nyíl a számláló növelése nélkül lép vissza a ciklushoz.
@abra megszamlalas

## A program
Az összegzéshez hasonlóan a kezdőérték a ciklus előtt áll. A feltételt egy elágazás vizsgálja, a számláló növelése pedig csak az <code>if</code> ágban történik.
```python
jegyek = [5, 3, 4, 5, 2, 5]
db = 0
for jegy in jegyek:
    if jegy == 5:
        db += 1
print("Ötösök száma:", db)   # 3
```

## Különbség az összegzéstől
A két tétel szerkezete hasonló, de nem szabad összekevernünk őket:
- az összegzésnél az <b>elem értékét</b> adjuk hozzá az összeghez (<code>osszeg += elem</code>)
- a megszámlálásnál mindig csak <b>1-et</b> adunk a számlálóhoz (<code>db += 1</code>), és csak akkor, ha a feltétel igaz
- az összegzés minden elemet felhasznál, a megszámlálás csak a megfelelőket számolja

## Összetett feltételek
A feltétel lehet összetett is: összehasonlító és logikai operátorokat kombinálhatsz. Ügyelj a feltétel pontos megfogalmazására, különösen a határoknál: a „10-nél nagyobb” <code>&gt; 10</code>, a „legalább 10” <code>&gt;= 10</code>.
```python
szamok = [12, 7, 18, 25, 3, 30]
db = 0
for szam in szamok:
    if szam % 3 == 0 and szam > 10:
        db += 1
print(db)   # 3, ezek: 12, 18, 30
```

## Arány és százalék
Ha a darabszámot elosztod az elemek számával, megkapod az arányt, 100-zal szorozva pedig a százalékot.
```python
jegyek = [4, 5, 3, 5]
db = 0
for jegy in jegyek:
    if jegy == 5:
        db += 1
print(db / len(jegyek) * 100, "%")   # 50.0 %
```

## Gyakori hibák
Ezekre figyelj:
- a számláló kezdőértéke hiányzik, ilyenkor NameError keletkezik
- a <code>db += 1</code> kikerül az <code>if</code> ágból, így minden elemet megszámol
- a <code>db += jegy</code> alakot írod <code>db += 1</code> helyett, így összegzést kapsz
- a kezdőértéket a ciklusba teszed, ezért a számláló minden körben nullázódik
