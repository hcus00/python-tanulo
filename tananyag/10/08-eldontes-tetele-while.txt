# Eldöntés tétele: van-e ilyen elem? (while)

## Mi a feladat?
Az <b>eldöntés</b> tétele azt kérdezi: <b>van-e</b> a sorozatban olyan elem, amely teljesít egy adott feltételt? A válasz egyetlen igen/nem érték (<code>True</code> vagy <code>False</code>). Példák: van-e elégtelen jegy a naplóban, van-e a listában negatív szám, szerepel-e a keresett név a névsorban.

## Miért while ciklussal?
Ha már az első megfelelő elemet megtaláltuk, a válasz igen, és nem kell tovább vizsgálni a többi elemet. Ezért az eldöntést <code>while</code> ciklussal oldjuk meg: addig lépünk az elemeken, amíg a keresett elemet meg nem találjuk, vagy el nem fogy a lista. A bejárást <b>indexszel</b> végezzük, hiszen tudnunk kell, meddig jutottunk.

## Az algoritmus szavakkal
Az eldöntés lépései:
- az indexet 0-ról indítjuk
- addig lépünk előre, amíg van még elem, és az aktuális elem NEM teljesíti a feltételt
- a ciklus után megnézzük, miért álltunk meg: ha az index még a listán belül van, találtunk ilyen elemet, egyébként nincs ilyen elem

## Az eldöntés folyamatábrán
Figyeld meg, hogy a ciklus <b>két</b> okból állhat le: vagy megtaláltuk a megfelelő elemet, vagy elfogytak az elemek. A ciklus után az <code>index &lt; len(l)</code> kérdés dönti el, melyik történt. Az <code>l</code> a lista nevét jelöli.
@abra eldontes

## A program
Nézzünk egy példát: van-e elégtelen jegy a listában? Az elégtelen az 1-es, ezért a ciklus addig megy, amíg az elem nem egyenlő 1-gyel.
```python
jegyek = [5, 4, 1, 3]
index = 0
while index < len(jegyek) and jegyek[index] != 1:
    index += 1
if index < len(jegyek):
    print("Van elégtelen jegy.")
else:
    print("Nincs elégtelen jegy.")
```

## Nyomkövetés
Kövessük az <code>index</code> értékét a fenti példában:
- index = 0: a jegy 5, nem 1, ezért lépünk
- index = 1: a jegy 4, nem 1, ezért lépünk
- index = 2: a jegy 1, a ciklus megáll
- az index = 2 kisebb, mint a lista hossza (4), tehát van elégtelen jegy
Ha nem lenne 1-es jegy, az index eljutna 4-ig, és a feltétel a lista végén hamissá válna.
<b>Tipp:</b> a Játszótéren (vagy bármelyik <b>▶ Kipróbálom</b> szerkesztőben) a <b>🔍 Lépésenként</b> gomb pontosan ezt csinálja: soronként végigköveti a programot, és megmutatja a változók értékét.

## A feltétel sorrendje számít
A ciklusfeltételben az <code>index &lt; len(l)</code> vizsgálatnak <b>előbb</b> kell szerepelnie, mint az elem vizsgálatának. Az <code>and</code> ugyanis balról jobbra értékel, és ha az első rész hamis, a másodikat már meg sem vizsgálja. Fordított sorrendnél, amikor az index már a lista végén van, a <code>l[index]</code> IndexError-t okozna.
```python
while jegyek[index] != 1 and index < len(jegyek):   # hiba: IndexError
    index += 1

while index < len(jegyek) and jegyek[index] != 1:    # helyes
    index += 1
```

## A ciklusfeltétel megfordítása
A ciklus addig fut, amíg a keresett tulajdonság <b>nem</b> igaz, ezért a ciklusfeltételben a keresett tulajdonság tagadása áll. Ezt érdemes jól begyakorolni:
- keresett: az elem egyenlő 1-gyel → a ciklus feltétele: <code>l[index] != 1</code>
- keresett: az elem nagyobb 10-nél → a ciklus feltétele: <code>l[index] &lt;= 10</code>
- keresett: az elem páros (<code>l[index] % 2 == 0</code>) → a ciklus feltétele: <code>l[index] % 2 != 0</code>
- keresett: az elem negatív (<code>l[index] &lt; 0</code>) → a ciklus feltétele: <code>l[index] &gt;= 0</code>

## Logikai érték
A válasz közvetlenül is megadható logikai változóként. Az <code>index &lt; len(l)</code> kifejezés <code>True</code>, ha találtunk megfelelő elemet.
```python
van = index < len(jegyek)
print(van)   # True
```
