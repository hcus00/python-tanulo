# Keresés tétele: hol az első ilyen elem? (while)

## Mi a feladat?
A <b>keresés</b> tétele azt kérdezi: ha van a sorozatban a feltételnek megfelelő elem, <b>hol</b> van? Az eldöntés csak azt mondta meg, hogy van-e ilyen elem, a keresés a helyét is megadja. Példák: hányadik helyen áll az első elégtelen jegy, hol van az első 10-nél nagyobb szám. Mivel nem biztos, hogy van ilyen elem, a „nincs” esetet is kezelnünk kell.

## Az algoritmus szavakkal
A ciklus ugyanaz, mint az eldöntésnél, a különbség a végén van:
- az <code>index</code> változót 0-ról indítjuk
- addig lépünk, amíg van még elem, és az aktuális elem nem felel meg
- a ciklus után: ha az <code>index</code> még a listán belül van, az <code>index</code> a keresett elem helye, egyébként nincs ilyen elem

## A keresés folyamatábrán
A ciklus ugyanaz, mint az eldöntésnél. A különbség: ha találtunk, nem azt írjuk ki, hogy van ilyen elem, hanem azt, <b>hol</b> van, vagyis az <code>index</code> értékét.
@abra kereses

## A program
Keressük meg az első elégtelen (1-es) jegyet! A <code>for</code> ciklus változóját (<code>i</code>) a bejárásra tartogatjuk, a keresésnél az <code>index</code> nevet használjuk, mert ez a keresett hely.
```python
jegyek = [5, 4, 1, 3, 1]
index = 0
while index < len(jegyek) and jegyek[index] != 1:
    index += 1
if index < len(jegyek):
    print("Az első elégtelen jegy indexe:", index)   # 2
else:
    print("Nincs elégtelen jegy.")
```

## Index vagy sorszám?
A feladat szövege dönti el, mit kell kiírni:
- az <b>index</b> a lista belső számozása, 0-tól indul
- a <b>sorszám</b> a hétköznapi „hányadik”, 1-től indul, ezért <code>index + 1</code>
- ha a szöveg azt kérdezi, „melyik indexen”, az <code>index</code> kell
- ha azt kérdezi, „hányadik elem”, az <code>index + 1</code> kell
```python
print("Indexe:", index)           # 2
print("Sorszáma:", index + 1)     # 3
```

## Index, sorszám, érték egy képen
A kiemelt elem <b>értéke</b> -2, <b>indexe</b> 2 (0-tól számolva), <b>sorszáma</b> 3 (1-től számolva). Mindig olvasd el pontosan a feladatot: melyiket kérdezi?
@abra index_sorszam

## Az elem értéke
Előfordulhat, hogy nem a helyet, hanem magát az elemet kérik. Ilyenkor a megtalált indexet visszahelyettesítjük a listába: <code>lista[index]</code>. Ez főleg akkor fontos, ha a feltételből nem derül ki az érték (például „10-nél nagyobb”). Ha a feltétel megadja az értéket (például „egyenlő 1-gyel”), nem kell kikeresni.
```python
szamok = [4, 8, 15, 6, 23]
index = 0
while index < len(szamok) and szamok[index] <= 10:
    index += 1
if index < len(szamok):
    print("Az első 10-nél nagyobb szám:", szamok[index])   # 15
    print("Indexe:", index)                                # 2
    print("Sorszáma:", index + 1)                          # 3
else:
    print("Nincs ilyen szám.")
```

## Eldöntés és keresés
A kettő összehasonlítva:
- az <b>eldöntés</b> kimenete igen/nem
- a <b>keresés</b> kimenete egy hely (vagy elem), illetve annak jelzése, hogy nincs ilyen
- a ciklus mindkettőnél azonos, csak az eredmény kiolvasása más
- a keresés mindig az <b>első</b> megfelelő elemet adja meg, a továbbiakat nem

## Összefoglalás
A keresés megadja az első megfelelő elem helyét, ha van ilyen. While ciklussal és index változóval oldjuk meg. A ciklus után az index &lt; len(l) vizsgálat dönti el, van-e találat. Az eredmény lehet index, sorszám (index + 1) vagy az elem értéke (lista[index]), ezt a feladat szövege dönti el.
