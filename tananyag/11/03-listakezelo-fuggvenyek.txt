# Listakezelő függvények és metódusok

## Függvény és metódus
A <code>len(l)</code> és a <code>sum(l)</code> alakban a lista paraméterként szerepel. A listametódusok viszont a lista <b>neve után, ponttal</b> állnak: <code>l.append(x)</code>. A metódus a listán dolgozik, sokszor át is írja azt. Az <code>append</code>-et és a rövidítéseket (<code>sum</code>, <code>count</code>, <code>in</code>, <code>index</code>, <code>min</code>, <code>max</code>) már ismered, ebben a témában a többi fontos műveletet rendszerezzük.

## Elem hozzáadása
Három lehetőség van:
- <code>l.append(x)</code> a lista <b>végére</b> fűzi az x elemet
- <code>l.insert(index, x)</code> az x elemet az adott helyre szúrja be, a későbbi elemek eggyel hátrébb csúsznak
- <code>l.extend(m)</code> az m lista összes elemét a végére fűzi
```python
l = [10, 20, 30]
l.append(40)
print(l)          # [10, 20, 30, 40]
l.insert(1, 15)
print(l)          # [10, 15, 20, 30, 40]
l.extend([50, 60])
print(l)          # [10, 15, 20, 30, 40, 50, 60]
```

## Elem törlése
Törlésre több módszer van:
- <code>l.remove(x)</code> az x érték <b>első</b> előfordulását törli; ha nincs ilyen elem, <code>ValueError</code> keletkezik
- <code>l.pop()</code> az utolsó elemet törli, és vissza is adja
- <code>l.pop(index)</code> az adott helyen lévő elemet törli, és vissza is adja
- <code>del l[index]</code> az adott helyen lévő elemet törli
- <code>l.clear()</code> az összes elemet törli
```python
l = [5, 8, 5, 3, 9]
l.remove(5)        # az első 5-öst törli
print(l)           # [8, 5, 3, 9]
utolso = l.pop()
print(utolso, l)   # 9 [8, 5, 3]
del l[0]
print(l)           # [5, 3]
```

## Rendezés
A rendezéshez több lehetőség van:
- <code>l.sort()</code> <b>helyben</b> rendezi a listát, vagyis az eredetit írja át, alapból növekvő sorrendbe; a <code>l.sort(reverse=True)</code> csökkenő sorrendbe rendez
- <code>sorted(l)</code> <b>új</b> rendezett listát ad vissza, az eredeti marad
- <code>l.reverse()</code> megfordítja a lista sorrendjét, de nem rendez
```python
l = [4, 9, 1, 7]
uj = sorted(l)
print(uj, l)       # [1, 4, 7, 9] [4, 9, 1, 7]
l.sort()
print(l)           # [1, 4, 7, 9]
l.sort(reverse=True)
print(l)           # [9, 7, 4, 1]
l.reverse()
print(l)           # [1, 4, 7, 9]
```

## Szövegek rendezése
Szövegek listája karakterkód szerint rendeződik, ezért a nagybetűs szavak a kisbetűsek előtt állnak, az ékezetes betűk pedig az ábécé végére kerülnek. Ezt a magyar ábécé szerinti rendezésnél figyelembe kell venni.
```python
nevek = ["Csilla", "anna", "Bence"]
print(sorted(nevek))   # Bence, Csilla, anna sorrendben
```

## Másolás: az = nem másol
Ha egy listát egyszerűen egy másik változónak adsz értékül (<code>m = l</code>), nem készül új lista: a két név <b>ugyanarra</b> a listára mutat, ezért az egyiken végzett módosítás a másikon is látszik. Valódi másolatot az <code>l.copy()</code> készít.
```python
l = [1, 2, 3]
m = l            # ugyanaz a lista, két névvel
m.append(4)
print(l)         # [1, 2, 3, 4]

k = l.copy()     # önálló másolat
k.append(5)
print(l)         # [1, 2, 3, 4]
print(k)         # [1, 2, 3, 4, 5]
```

## Listák összefűzése és létrehozása
A <code>+</code> két lista elemeiből új listát készít, a <code>*</code> ismétli a listát. Utóbbi hasznos adott méretű, azonos elemekkel feltöltött lista létrehozására. A <code>list(range(...))</code> számsorozatból készít listát.
```python
a = [1, 2]
b = [3, 4]
print(a + b)               # [1, 2, 3, 4]
print([0] * 5)             # [0, 0, 0, 0, 0]
print(list(range(1, 6)))   # [1, 2, 3, 4, 5]
```

## Gyakori hibák
Ezekre figyelj:
- <code>l = l.sort()</code>: a <code>sort</code> nem ad vissza listát, hanem <code>None</code>-t (ez azt jelenti, hogy nincs érték), ezért a lista elvész
- <code>l.remove(x)</code>, ha az x nincs a listában: <code>ValueError</code>
- <code>l.pop()</code> üres listán: <code>IndexError</code>
- <code>m = l</code> másolás helyett: a két név ugyanazt a listát jelöli
- lista elemeinek törlése bejárás közben: kimaradhatnak elemek, ilyenkor inkább új listát építs
```python
l = [3, 1, 2]
l = l.sort()
print(l)    # None
```

## Összefoglaló
Melyik műveletet mikor használd:
- hozzáadás: <code>append</code>, <code>insert</code>, <code>extend</code>
- törlés: <code>remove</code>, <code>pop</code>, <code>del</code>, <code>clear</code>
- rendezés: <code>sort</code> (helyben), <code>sorted</code> (új lista), <code>reverse</code>
- információ: <code>len</code>, <code>count</code>, <code>index</code>, <code>in</code>, <code>min</code>, <code>max</code>, <code>sum</code>
- másolás: <code>copy</code>, az <code>=</code> nem másol
- építés: <code>+</code>, <code>*</code>, <code>list(range(...))</code>
