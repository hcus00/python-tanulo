## Milyen feladatokra számíthatsz?
A korábbi feladatsorokban például szerepelt egy szójáték (Kitaláló), egy dobókockás szimuláció (Kockák) és egy adatsor feldolgozása megszámlálással (Létra). A feladatok jellemzően egy kis <b>történetbe</b> vannak ágyazva: játék, szimuláció, menetrend, névsor, üzenet. Közös vonásaik:
- a feladat több, sorszámozott részfeladatra bomlik, és a részfeladatok sokszor egymásra épülnek
- <b>nem írja ki, melyik programozási tételt kell használnod</b>: a leírásból neked kell felismerned, hogy összegzésre, megszámlálásra, keresésre vagy szélsőérték-kiválasztásra van szükség
- a kérdőszövegeket és a kimenet formáját pontosan megadja, általában mintakimenettel
- megadja, milyen néven kell mentened a forráskódot
- a részfeladatok többnyire egymástól függetlenül megoldhatók: ha az egyik nem sikerül, a többi még megoldható
- a kiírásnál az ékezetmentes változatot is elfogadták
A feladatok többsége a tanult elemekből építkezik: véletlen számok, ciklusok, listák, szövegkezelés és programozási tételek, de gyakran egy-egy különleges esettel (üres találat, holtverseny, a lista vége). Az alábbi négy típusfeladat saját készítésű, a szerkezetük viszont a valódi feladatokét követi: más-más történet, más-más adatforrás, más-más feladattípus. A megoldások lenyitható blokkokban vannak: előbb próbáld meg magad megoldani a feladatot.

## Honnan jönnek az adatok?
Három forrás fordul elő:
- a program <b>generálja</b> az adatot (például véletlen kockadobás vagy pörgetés)
- a felhasználó <b>megadja</b> (<code>input</code>)
- az adatokat <b>készen</b> kapod a feladat szövegében (például egy táblázat, menetrend vagy névsor), és neked kell a programban eltárolnod őket
A gyakorló feladatokban mindhárom módszer előfordul. A feladat nem árulja el, milyen adatszerkezetben tárold az adatokat, ezt neked kell eldöntened. Ha az adatok táblázatban vannak megadva, érdemes az oszlopaikat listákba, vagy a sorokat egy listába írni, a feldolgozás utána ugyanaz a bejárás és ugyanazok a tételek. Véletlen számoknál figyelj arra, hogy a feladat pontosan megadja, hányszor és milyen sorrendben sorsolj.
```python
# a feladat szövegében megadott adatok
szavak = ["alma", "körte", "szilva"]

# a program generálja
import random
dobas = random.randint(1, 6)

# a felhasználó adja meg
nev = input("Neved: ")
```

## Megoldás: Szerencsekerék
Itt nem egy klasszikus programozási tételt kell alkalmazni, hanem egy <b>folyamatot</b> kell szimulálni: a pontszám minden pörgetésnél a korábbi állapottól függ. A megoldás elemei:
- a ciklusnak <b>két leállási feltétele</b> van: elfogytak a pörgetések, vagy megvan a nagydíj. Ezért <code>while</code> ciklust használunk, a <code>nagydij</code> logikai jelzővel
- a bukónál a <code>//</code> osztás adja a pontok felét lefelé kerekítve
- a ciklus után csak akkor írjuk ki a végső állást, ha nem volt nagydíj
```python
import random

mezok = [0, 5, 10, 20, 50]
n = int(input("Pörgetések: "))
pont = 0
nagydij = False
porgetes = 0
while porgetes < n and not nagydij:
    porgetes += 1
    mezo = mezok[random.randint(0, 4)]
    if mezo == 0:
        pont = pont // 2
    else:
        pont += mezo
    print(f"{porgetes}. pörgetés: {mezo} pont, állás: {pont}")
    if pont >= 100:
        nagydij = True
        print(f"Nagydíj a {porgetes}. pörgetésnél!")
if not nagydij:
    print("Vége a játéknak, végső állás:", pont)
```

## Megoldás: E-mail cím
Ez a feladat <b>szövegkezelés</b>, tételek nélkül:
- a <code>split</code> bontja szavakra a nevet
- a monogramot a szavak bejárásával építjük, minden szó első betűje (<code>szo[0]</code>) után pont és szóköz jön, a végén a <code>strip()</code> levágja a felesleges szóközt
- az ékezetek cseréjéhez két, egyforma hosszú szöveget használunk: ahol az ékezetes betű az <code>ekezetes</code> szövegben van, ott a párja a <code>sima</code> szöveg ugyanazon indexén áll. Az <code>index</code> megadja a helyét
- a <code>lower()</code> az ékezetes nagybetűket is kisbetűvé alakítja (<code>Ő</code> helyett <code>ő</code>), ezért előbb kisbetűsítünk, utána cserélünk
```python
nev = input("Teljes név: ")
szavak = nev.split(" ")

monogram = ""
for szo in szavak:
    monogram += szo[0] + ". "
print("Monogram:", monogram.strip())

ekezetes = "áéíóöőúüű"
sima = "aeiooouuu"
cim = (szavak[0] + "." + szavak[1]).lower()
vegso = ""
for betu in cim:
    if betu in ekezetes:
        vegso += sima[ekezetes.index(betu)]
    else:
        vegso += betu
print("E-mail cím:", vegso + "@suli.hu")
```

5. Írd ki, melyik két egymást követő busz között a leghosszabb a szünet (az elsőt, ha több egyforma van): <code>Leghosszabb szünet: 50 perc (8:10 és 9:00 között)</code>

## Megoldás: Buszmenetrend
A feladat három része három különböző gondolkodásmód:
- a szövegből számot készítő <b>átalakítás</b>: <code>split(":")</code>, majd <code>óra * 60 + perc</code>. Percekben már könnyű összehasonlítani és kivonni
- az első olyan busz <b>keresése</b>, amely nem indult el az adott időpont előtt. Ez <code>while</code> ciklus <code>index</code> változóval, mert a keresés megáll az első találatnál. Ha az <code>index</code> a lista végére ér, nincs több busz
- a leghosszabb szünet <b>szélsőérték-kiválasztás</b> az egymást követő elemek különbségére. A <code>range</code> ezért az 1. indextől indul, és a különbség az <code>i</code>-edik és az <code>i - 1</code>-edik elemből áll elő. A kiíráshoz az eredeti szöveges időpontokat használjuk, így nem kell visszaalakítani a perceket
```python
indulasok = ["5:50", "6:20", "6:48", "7:05", "7:35", "8:10", "9:00"]

percek = []
for ido in indulasok:
    adat = ido.split(":")
    percek.append(int(adat[0]) * 60 + int(adat[1]))

most = input("Hány óra van? ").split(":")
mostperc = int(most[0]) * 60 + int(most[1])

index = 0
while index < len(percek) and percek[index] < mostperc:
    index += 1
if index < len(percek):
    print("Következő busz: " + indulasok[index] + " (" + str(percek[index] - mostperc) + " perc múlva)")
else:
    print("Ma már nincs több busz.")

legnagyobb = 0
hol = 0
for i in range(1, len(percek)):
    kulonbseg = percek[i] - percek[i - 1]
    if kulonbseg > legnagyobb:
        legnagyobb = kulonbseg
        hol = i
print("Leghosszabb szünet: " + str(legnagyobb) + " perc (" + indulasok[hol - 1] + " és " + indulasok[hol] + " között)")
```

## 4. típusfeladat: Huszonegy
Egyszerűsített kártyajátékot játszol a bankkal. Te a saját lapjaidból már összeállítottál egy összeget (4 és 21 közötti egész szám). A bank lapot húz: minden lap értéke 1 és 10 közötti véletlen egész szám, és a bank addig húz, amíg az összege el nem éri a 17-et. Ha a bank összege ennél is több, mint 21, a bank <b>bukott</b>. Készíts programot <b>huszonegy</b> néven!
1. Kérd be a saját összegedet a <code>"Te összeged: "</code> felirattal.
2. Szimuláld a bank húzásait: minden lap értékét sorsold ki az 1 és 10 közötti egész számok közül (mindkét határ lehet), húzásonként pontosan egy sorsolással.
3. Minden húzás után írd ki a lap értékét és a bank eddigi összegét: <code>Húzott lap: 4, összeg: 4</code>
4. A húzások végén döntsd el, ki nyert. Ha a bank bukott, ezt írd ki: <code>A bank bukott, te nyertél!</code> Egyébként az nyer, akinek nagyobb az összege: <code>A bank nyert.</code>, <code>Te nyertél!</code>, egyenlő összegnél pedig <code>Döntetlen.</code>
A mintakimenet véletlen értékeket tartalmaz, a te programod más számokat is adhat.
```python
Mintakimenet:
Te összeged: 18
Húzott lap: 4, összeg: 4
Húzott lap: 10, összeg: 14
Húzott lap: 9, összeg: 23
A bank bukott, te nyertél!
```

## Megoldás: Huszonegy
A feladat két fő része:
- a bank húzása egy <b>feltételes ciklus</b>: addig ismétlődik, amíg az összeg 17 alatt van. Nem tudjuk előre, hányszor, ezért a <code>for</code> nem illik ide
- az eredmény <b>többágú elágazás</b>. A sorrend számít: előbb a bukást vizsgáljuk, mert ha a bank összege 21 fölött van, a nagyobb/kisebb összehasonlításnak már nincs értelme
```python
import random

jatekos = int(input("Te összeged: "))
bank = 0
while bank < 17:
    lap = random.randint(1, 10)
    bank += lap
    print(f"Húzott lap: {lap}, összeg: {bank}")

if bank > 21:
    print("A bank bukott, te nyertél!")
elif bank > jatekos:
    print("A bank nyert.")
elif bank < jatekos:
    print("Te nyertél!")
else:
    print("Döntetlen.")
```

Minden pörgetésnél sorsolj egy mezőt (mind az öt egyforma eséllyel, pörgetésenként pontosan egy sorsolással), a 0 mezőn a pontszám fele elvész (lefelé kerekítve), a többi mezőn a pontok hozzáadódnak. Minden pörgetés után írd ki: <code>1. pörgetés: 5 pont, állás: 5</code>. Ha az állás eléri a 100-at, írd ki: <code>Nagydíj a 10. pörgetésnél!</code> és állj meg. Ha N pörgetés után sincs nagydíj: <code>Vége a játéknak, végső állás: ...</code>. A tesztek rögzített véletlen sorozattal futnak, ezért számít, hányszor és milyen sorrendben sorsolsz.
kezdokod: |
  import random
  mezok = [0, 5, 10, 20, 50]
  n = int(input())

megoldas: |
  import random
  mezok = [0, 5, 10, 20, 50]
  n = int(input())
  pont = 0
  nagydij = False
  porgetes = 0
  while porgetes < n and not nagydij:
      porgetes += 1
      mezo = mezok[random.randint(0, 4)]
      if mezo == 0:
          pont = pont // 2
      else:
          pont += mezo
      print(f"{porgetes}. pörgetés: {mezo} pont, állás: {pont}")
      if pont >= 100:
          nagydij = True
          print(f"Nagydíj a {porgetes}. pörgetésnél!")
  if not nagydij:
      print("Vége a játéknak, végső állás:", pont)

- 1 || seed: 4
- 6 || seed: 4
segitseg: Két leállási feltétel van, ezért <code>while</code> ciklus kell, egy logikai jelzővel a nagydíjnak.

Ö.</code> (a szavak kezdőbetűi ponttal, szóközzel elválasztva). Majd írd ki az e-mail címet: <code>E-mail cím: ori.odon@suli.hu</code>: az első szó, pont és a második szó kisbetűvel és ékezetek nélkül (<code>áéíóöőúüű</code> helyett <code>aeiooouuu</code>), utána <code>@suli.hu</code>.
kezdokod: |
  nev = input()
  szavak = nev.split(" ")

megoldas: |
  nev = input()
  szavak = nev.split(" ")
  monogram = ""
  for szo in szavak:
      monogram += szo[0] + ". "
  print("Monogram:", monogram.strip())
  ekezetes = "áéíóöőúüű"
  sima = "aeiooouuu"
  cim = (szavak[0] + "." + szavak[1]).lower()
  vegso = ""
  for betu in cim:
      if betu in ekezetes:
          vegso += sima[ekezetes.index(betu)]
      else:
          vegso += betu
  print("E-mail cím:", vegso + "@suli.hu")

kerdes: <b>Buszmenetrend.</b> Az indulások ideje <code>ó:p</code> alakú szövegként adott, időrendben. Kérd be az aktuális időt ugyanilyen alakban (felirat nélkül). Írd ki a következő busz idejét és hogy hány perc múlva indul: <code>Következő busz: 6:48 (18 perc múlva)</code>. Ha pont most indul, 0 perc a várakozás, ha nincs több busz: <code>Ma már nincs több busz.</code> Ezután írd ki a leghosszabb szünetet két egymást követő busz között (az első ilyen): <code>Leghosszabb szünet: 50 perc (8:10 és 9:00 között)</code>. <b>Az első sort ne módosítsd.</b>
kezdokod: |
  indulasok = ["5:50", "6:20", "6:48", "7:05", "7:35", "8:10", "9:00"]

megoldas: |
  indulasok = ["5:50", "6:20", "6:48", "7:05", "7:35", "8:10", "9:00"]
  percek = []
  for ido in indulasok:
      adat = ido.split(":")
      percek.append(int(adat[0]) * 60 + int(adat[1]))
  most = input().split(":")
  mostperc = int(most[0]) * 60 + int(most[1])
  index = 0
  while index < len(percek) and percek[index] < mostperc:
      index += 1
  if index < len(percek):
      print("Következő busz: " + indulasok[index] + " (" + str(percek[index] - mostperc) + " perc múlva)")
  else:
      print("Ma már nincs több busz.")
  legnagyobb = 0
  hol = 0
  for i in range(1, len(percek)):
      kulonbseg = percek[i] - percek[i - 1]
      if kulonbseg > legnagyobb:
          legnagyobb = kulonbseg
          hol = i
  print("Leghosszabb szünet: " + str(legnagyobb) + " perc (" + indulasok[hol - 1] + " és " + indulasok[hol] + " között)")

kerdes: <b>Huszonegy.</b> Kérd be a saját összegedet (felirat nélkül). A bank addig húz, amíg az összege el nem éri a 17-et; minden lap értékét sorsold ki az 1 és 10 közötti egész számok közül, húzásonként pontosan egy sorsolással. Minden húzás után írd ki: <code>Húzott lap: 4, összeg: 4</code>. A végén: ha a bank összege 21 fölött van, <code>A bank bukott, te nyertél!</code>, különben a nagyobb összeg nyer (<code>A bank nyert.</code> vagy <code>Te nyertél!</code>), egyenlőség esetén <code>Döntetlen.</code> A tesztek rögzített véletlen sorozattal futnak, ezért számít, hányszor és milyen sorrendben sorsolsz.
kezdokod: |
  import random
  jatekos = int(input())

megoldas: |
  import random
  jatekos = int(input())
  bank = 0
  while bank < 17:
      lap = random.randint(1, 10)
      bank += lap
      print(f"Húzott lap: {lap}, összeg: {bank}")
  if bank > 21:
      print("A bank bukott, te nyertél!")
  elif bank > jatekos:
      print("A bank nyert.")
  elif bank < jatekos:
      print("Te nyertél!")
  else:
      print("Döntetlen.")

- 18 || seed: 3
- 18 || seed: 4
- 18 || seed: 7
- 10 || seed: 1
segitseg: A húzás <code>while bank &lt; 17</code> ciklus. A döntésnél a bukást vizsgáld elsőként.
