# Típusátalakítás és karakterláncok

## Miért kell átalakítani?
A Python nem keveri a típusokat: egy szöveghez nem adhatsz hozzá számot. Ilyenkor az értéket át kell alakítani. Az átalakító függvények: <code>int()</code> egész számmá, <code>float()</code> tizedes törtté, <code>str()</code> szöveggé alakít.
```python
szam = int("42")      # szöveg → egész: 42
ar = float("2.5")     # szöveg → tizedes tört: 2.5
szoveg = str(7)       # szám → szöveg: "7"
print(int(3.9))       # 3, a tizedes rész levágódik, nem kerekít!
print(float(5))       # 5.0
```

## Mikor nem sikerül az átalakítás?
Ha a szöveg nem számot tartalmaz, <code>ValueError</code> keletkezik: az <code>int("abc")</code> hibás. A tizedes törtet tartalmazó szöveget sem lehet közvetlenül egésszé alakítani, ilyenkor előbb <code>float()</code>, utána <code>int()</code> kell.
```python
print(int(float("2.5")))   # 2
```

## Karakterláncok
A <b>karakterlánc</b> (str) karakterek sorozata. A példáinkban dupla idézőjellel adjuk meg, az üres szöveg <code>""</code>. A <code>"5"</code> szöveg, az <code>5</code> szám, ezért <code>"5" + "3"</code> összefűz (53), az <code>5 + 3</code> összead (8). A <code>+</code> szövegeket fűz össze, a <code>*</code> ismétel.
```python
nev = "Anna"
print("Szia, " + nev + "!")   # Szia, Anna!
print("ha" * 3)                # hahaha
print("5" + "3")               # 53
print(5 + 3)                   # 8
```

## Hossz és karakterek elérése
A <code>len()</code> megadja a karakterlánc hosszát. Az egyes karakterek <b>index</b> szerint érhetők el, az index 0-tól indul, a negatív index hátulról számol.
```python
szo = "Python"
print(len(szo))   # 6
print(szo[0])     # P
print(szo[-1])    # n
```

## Az indexek képen
A szöveg karaktereit a Python <b>0-tól</b> kezdve sorszámozza. A negatív index hátulról számol: a <code>-1</code> az utolsó karakter. Egy <code>n</code> hosszú szövegnél az érvényes indexek <code>0</code>-tól <code>n-1</code>-ig, illetve <code>-n</code>-től <code>-1</code>-ig tartanak.

## Szöveg és szám együtt
A <code>print("Kor: " + 16)</code> TypeError-t ad, mert szöveghez számot adtunk. Két jó megoldás: átalakítjuk a számot, vagy vesszővel külön adjuk át.
```python
print("Kor: " + str(16))   # Kor: 16
print("Kor:", 16)          # Kor: 16
```

## Összefoglalás
Az int(), float(), str() átalakít. Az int() levág, nem kerekít. A + szöveget fűz, a * ismétel. A len() a hosszt adja, az index 0-tól indul. Szöveget és számot nem lehet közvetlenül összeadni.
