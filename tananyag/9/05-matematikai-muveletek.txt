# Matematikai műveletek

## Alapműveletek
Az összeadás <code>+</code>, a kivonás <code>-</code>, a szorzás <code>*</code>, az osztás <code>/</code>. Az osztás eredménye mindig tizedes tört (float), akkor is, ha az eredmény egész.
```python
print(7 + 2)   # 9
print(7 - 2)   # 5
print(7 * 2)   # 14
print(7 / 2)   # 3.5
print(6 / 3)   # 2.0
```

## Egész osztás és maradék
A <code>//</code> az egész osztás hányadosát, a <code>%</code> a maradékot adja. Mivel 17 = 3 · 5 + 2, ezért 17 // 5 = 3 és 17 % 5 = 2. Ezekkel dönthető el, hogy egy szám páros-e (<code>n % 2 == 0</code>), vagy ezekkel választható le egy szám utolsó számjegye.
```python
print(17 // 5)     # 3
print(17 % 5)      # 2
print(1234 % 10)   # 4, az utolsó számjegy
print(1234 // 10)  # 123, az utolsó számjegy nélkül
```

## Hányados és maradék képen
A <code>17 // 5</code> azt kérdezi, hány <b>teljes</b> ötös csoport kerül a 17-be (3). A <code>17 % 5</code> azt, hogy mennyi <b>marad</b> a csoportok után (2). A két művelet együtt adja a számot: <code>17 = 3 · 5 + 2</code>.
@abra maradek

## Hatványozás és műveleti sorrend
A <code>**</code> a hatványozás. A sorrend ugyanaz, mint a matematikában: zárójel, hatványozás, szorzás/osztás/maradék, összeadás/kivonás. Egyenrangú műveleteknél balról jobbra számol, kivéve a hatványozást, ott jobbról balra.
```python
print(2 ** 3)        # 8
print(2 + 3 * 4)     # 14
print((2 + 3) * 4)   # 20
print(2 ** 3 ** 2)   # 512
```

## Hasznos beépített függvények
Az <code>abs()</code> abszolútértéket, a <code>round(x, n)</code> n tizedesre kerekítést, a <code>min()</code> és a <code>max()</code> a legkisebb és a legnagyobb értéket adja.
```python
print(abs(-5))           # 5
print(round(2.567, 2))   # 2.57
print(max(3, 9, 4))      # 9
```

## Gyökvonás és a math modul
A négyzetgyököt a <code>math</code> modul <code>sqrt()</code> függvénye adja. A modult a program elején be kell kapcsolni az <code>import math</code> utasítással, a függvényt pedig a modul nevével együtt hívod: <code>math.sqrt()</code>. Gyököt hatványozással is vonhatsz: a <code>0.5</code> kitevő a négyzetgyök. A <code>math.pi</code> a π értéke. A négyzetgyök eredménye mindig <b>float</b>.
```python
import math
print(math.sqrt(81))   # 9.0
print(81 ** 0.5)       # 9.0
print(math.pi)         # 3.141592653589793
```

## Kerekítés és a tizedestörtek pontatlansága
A számítógép a tizedestörteket kettes számrendszerben tárolja, ezért néha apró pontatlanság jelenik meg. Emiatt két tizedestört egyenlőségét ne <code>==</code> jellel vizsgáld, és kiíráskor érdemes kerekíteni. Figyelj a <code>round()</code> szabályára is: a pontosan <b>.5</b>-re végződő számot a <b>páros</b> szomszéd felé kerekíti, ez eltér az iskolai kerekítéstől. Ha egy feladatban a „fél felfelé” szabály kell, azt másképp kell megoldani (például a hányados és a maradék segítségével).
```python
print(0.1 + 0.2)             # 0.30000000000000004
print(round(0.1 + 0.2, 2))   # 0.3
print(round(2.5))            # 2
print(round(3.5))            # 4
```

## Összevont operátorok
Programozás közben gyakran kell egy változó értékét a régi értékéből kiszámolni, például <code>x = x + 1</code>. Erre rövidebb írásmód az <b>összevont (értékadó) operátor</b>: <code>x += 1</code>. Minden művelethez van ilyen: <code>+=</code>, <code>-=</code>, <code>*=</code>, <code>/=</code>, <code>//=</code>, <code>%=</code>, <code>**=</code>. Később ezekkel számolunk összeget (<code>s += x</code>) és darabszámot (<code>db += 1</code>).
```python
x = 10
x += 5     # x = x + 5    → 15
x -= 3     # x = x - 3    → 12
x *= 2     # x = x * 2    → 24
x //= 5    # x = x // 5   → 4
x %= 3     # x = x % 3    → 1
x **= 4    # x = x ** 4   → 1
```

## Összefoglalás
A / mindig float-ot ad, a // egész hányadost, a % maradékot. A ** hatvány. A műveleti sorrend a matematikai. Az összevont operátorok (+=, -=, *=, …) a változó régi értékét módosítják. A négyzetgyökhöz a math.sqrt (import math) vagy a ** 0.5 kell. A round() a pontosan .5-re végződő számot a páros szám felé kerekíti, és a tizedestörtek kicsit pontatlanok lehetnek.
