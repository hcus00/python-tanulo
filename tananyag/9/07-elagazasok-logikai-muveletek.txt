# Elágazás (if–else) és logikai műveletek

## Miért kell elágazás?
Eddig a programjaink mindig ugyanazokat a lépéseket hajtották végre. Az elágazás lehetővé teszi, hogy a program <b>döntsön</b>: egy feltétel igaz vagy hamis volta alapján más-más utasításokat hajt végre. A folyamatábrán ezt a rombusz jelölte.

## Az if-else szerkezet
Az <code>if</code> után áll a feltétel, majd kettőspont. Ha a feltétel igaz, a beljebb húzott utasítások futnak le. Az <code>else</code> ág akkor fut le, ha a feltétel hamis, ez az ág elhagyható. A <b>behúzás</b> (négy szóköz) jelzi, mely utasítások tartoznak az ághoz.
```python
szam = int(input("Adj meg egy számot: "))
if szam % 2 == 0:
    print("páros")
else:
    print("páratlan")
```

## Az if-else folyamatábrán
Ugyanez az elágazás folyamatábrán. A rombusz két kimenete az <code>if</code> és az <code>else</code> ág. Mindkét ág után a program ugyanott folytatódik, a STOP jelnél.
@abra paros

## Összehasonlító operátorok
A feltétel mindig logikai értéket (<code>True</code> vagy <code>False</code>) ad. Az összehasonlító operátorok: <code>==</code> (egyenlő), <code>!=</code> (nem egyenlő), <code>&lt;</code>, <code>&gt;</code>, <code>&lt;=</code>, <code>&gt;=</code>. Ne keverd össze az <code>=</code> jelet (értékadás) a <code>==</code> jellel (összehasonlítás)!
```python
print(5 == 5)             # True
print(5 != 5)             # False
print(3 < 2)              # False
print(4 >= 4)             # True
print("alma" == "alma")   # True
```

## Logikai műveletek
Több feltételt összekapcsolhatsz. Az <code>and</code> (és) akkor igaz, ha mindkét feltétel igaz. Az <code>or</code> (vagy) akkor igaz, ha legalább az egyik igaz. A <code>not</code> megfordítja az értéket. A kiértékelés sorrendje: <code>not</code>, majd <code>and</code>, majd <code>or</code>, zárójellel ez módosítható.
```python
kor = 15
print(kor >= 12 and kor <= 18)   # True, mindkettő igaz
print(kor < 10 or kor > 14)      # True, az egyik igaz
print(not kor > 20)              # True, a tagadás
print(12 <= kor <= 18)           # True, rövidebb alak
```

## Gyakori hibák
Három tipikus hiba: <code>=</code> írása <code>==</code> helyett, a kettőspont elhagyása, és a rossz behúzás. Az első és a második SyntaxError-t okoz, a hiányzó behúzás IndentationError-t.
```python
if szam = 5:     # hibás: = helyett ==
if szam == 5     # hibás: hiányzik a kettőspont
```

## Összefoglalás
Az if feltétel igaz esetén, az else hamis esetén fut. A feltétel logikai érték. Összehasonlítás: ==, !=, <, >, <=, >=. Logikai műveletek: and, or, not. Az ágakat behúzás jelöli.
