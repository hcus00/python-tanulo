# Többágú (elif) és egymásba ágyazott elágazás

## Több ágú elágazás: elif
Ha kettőnél több eset van, az <code>elif</code> (az "else if" rövidítése) segít. A Python a feltételeket <b>sorban</b> vizsgálja, az első igaz ág fut le, a többit már kihagyja. Az utolsó <code>else</code> azokat az eseteket fogja fel, amelyekre egyik feltétel sem igaz.
```python
pont = int(input("Pontszám: "))
if pont >= 90:
    jegy = 5
elif pont >= 75:
    jegy = 4
elif pont >= 60:
    jegy = 3
else:
    jegy = 2
print("Jegy:", jegy)
```

## Az elif lánc folyamatábrán
Az <code>elif</code> lánc olyan, mint egymás alá fűzött rombuszok. Ha egy kérdésre <b>igen</b> a válasz, jobbra kilépünk, és beállítjuk a jegyet. Ha <b>nem</b>, lefelé lépünk a következő kérdéshez. Az utolsó, kérdés nélküli ág az <code>else</code>. A jobb oldali vonal azt mutatja, hogy a kiírás már mindegyik ágnál közös.
@abra jegy

## A sorrend számít
Mivel az első igaz ág lefut, a feltételeket úgy kell sorba tenni, hogy ne fedjék el egymást. Ha a pont >= 60 vizsgálat az első lenne, a 95 pont is hármast kapna.
```python
pont = 95
if pont >= 60:
    print(3)    # ez fut le, pedig ötös kellene
elif pont >= 90:
    print(5)    # ide már el sem jut
```

## Elágazások egymásba ágyazása
Egy ág belsejében újabb elágazás is lehet. Ilyenkor a behúzás szintje mutatja meg, melyik <code>else</code> melyik <code>if</code>-hez tartozik.
```python
szam = int(input("Szám: "))
if szam > 0:
    if szam % 2 == 0:
        print("pozitív páros")
    else:
        print("pozitív páratlan")
else:
    print("nem pozitív")
```

## Melyiket mikor használd?
Az <code>elif</code> akkor jó, ha egymást kizáró esetek vannak ugyanarra a mennyiségre (például pontszám és jegy). A beágyazás akkor jó, ha egy második döntés csak az első eredményétől függően kell. Sokszor az <code>and</code> is egyszerűsíthet: <code>if szam > 0 and szam % 2 == 0:</code> egyetlen feltétel.

## Összetett példa: szökőév
Egy év szökőév, ha osztható 4-gyel, de a 100-zal oszthatók közül csak akkor, ha 400-zal is. A feltételeket a legkülönlegesebb esettől haladva kell sorba állítani: 2000 szökőév, 1900 nem, 2024 igen.
```python
ev = int(input("Év: "))
if ev % 400 == 0:
    print("szökőév")
elif ev % 100 == 0:
    print("nem szökőév")
elif ev % 4 == 0:
    print("szökőév")
else:
    print("nem szökőév")
```

## Összefoglalás
Az elif több esetet kezel, az első igaz ág fut le, ezért a sorrend számít. Az elágazások egymásba ágyazhatók, a behúzás mutatja a hozzátartozást. Az and és or gyakran kiválthatja a beágyazást.
