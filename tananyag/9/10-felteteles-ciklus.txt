# Feltételes ciklus (while)

## Mikor kell feltételes ciklus?
Néha nem tudjuk előre, hányszor kell ismételni, például amíg a felhasználó helyes adatot nem ír be, vagy amíg egy szám el nem ér egy határt. Ilyenkor a <b>feltételes ciklust</b> használjuk, amely addig ismétel, amíg a feltétel igaz.

## A while szerkezet
A <code>while</code> ciklus a feltételt a törzs <b>előtt</b> vizsgálja. Ha igaz, lefut a törzs, aztán újra vizsgál. Ha a feltétel már az elején hamis, a törzs egyszer sem fut le. Három dolgra kell figyelni: kezdőérték, feltétel, léptetés.
```python
n = 1                 # kezdőérték
while n <= 5:         # feltétel
    print(n)
    n += 1            # léptetés
```

## Végtelen ciklus
Ha a feltétel sosem válik hamissá, a ciklus sosem áll le. Ez a leggyakoribb while hiba. Szinte mindig az hiányzik, hogy a törzs megváltoztassa a feltételben szereplő változót.
```python
n = 1
while n <= 5:
    print(n)      # hiba: n nem változik, a ciklus sosem áll le
```

## Tipikus feladatok
Az első példa addig kér adatot, amíg az megfelelő. A második egy szám számjegyeit számolja: minden lépésben levágja az utolsó számjegyet (az egész osztással), és eggyel növeli a számlálót.
```python
szam = int(input("Pozitív szám: "))
while szam <= 0:
    print("Hibás adat!")
    szam = int(input("Pozitív szám: "))
print("Rendben:", szam)

n = 1234
db = 0
while n > 0:
    n = n // 10
    db += 1
print(db)       # 4
```

## Az adatellenőrzés folyamatábrán
Az első példa folyamatábrája: ha a beírt szám nem pozitív, kiírjuk a hibaüzenetet, és <b>visszatérünk az adatbekéréshez</b>. Csak akkor lépünk ki a ciklusból, ha a szám megfelelő. Ez is egy feltételes ciklus: addig ismétlünk, amíg a feltétel igaz.

## For vagy while?
Ha előre tudod, hányszor kell ismételni, a <code>for</code> a kényelmesebb. Ha az ismétlések száma a feltételtől függ, a <code>while</code> való. A <code>break</code> utasítás a ciklusból azonnal kilép, de a feladatok többségét nélküle is jól meg lehet oldani.
