  A szülői szervezet tombolát rendez. Az 1-től 90-ig számozott szelvények közül egymás után annyiszor sorsolnak, ahány nyereményt kisorsolnak. Minden sorsolásnál bármelyik szelvény egyforma eséllyel nyerhet, és ugyanaz a szelvény többször is kisorsolható. A feladatban a sorsolást szimulálod: a nyeremények számát (N, 1 ≤ N ≤ 20) a felhasználó adja meg, helyességét nem kell ellenőrizni.

megoldas: |
  import random

  n = int(input("Hány nyereményt sorsolnak? "))
  szamok = []
  for i in range(n):
      szamok.append(random.randint(1, 90))

  print("1. feladat")
  print(*szamok)

  print("2. feladat")
  paros = 0
  for szam in szamok:
      if szam % 2 == 0:
          paros += 1
  print("Páros számok:", paros)

  print("3. feladat")
  legnagyobb = 0
  for i in range(n):
      if szamok[i] > szamok[legnagyobb]:
          legnagyobb = i
  print("A legnagyobb szám:", szamok[legnagyobb], "(" + str(legnagyobb + 1) + ". sorsolás)")

  print("4. feladat")
  novekedes = 0
  for i in range(1, n):
      if szamok[i] > szamok[i - 1]:
          novekedes += 1
  print("Növekedések száma:", novekedes)
