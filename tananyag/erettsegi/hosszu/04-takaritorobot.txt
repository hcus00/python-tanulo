# A takarítórobot
ido: 60
leiras: |
  Egy takarítórobot egy hosszú, egyenes folyosón dolgozik. A folyosó szakaszait egész számok jelölik, a robot a <b>0. szakaszról</b> indul. A robot parancsokat kap egyetlen szövegben, karakterenként egy-egy parancsot. A robot a következő parancsokat ismeri:
  - <code>E</code>: egy szakaszt előre lép (a szakasz száma eggyel nő)
  - <code>H</code>: egy szakaszt hátra lép (a szakasz száma eggyel csökken)
  - <code>T</code>: helyben marad és kitakarítja azt a szakaszt, amelyen áll
  Minden más karaktert a robot nem ért, ezeket kihagyja (nem mozdul és nem takarít). A parancsok szövege legalább egy karakter hosszú. Készíts programot, amely nyomon követi a robot útját!
reszek:
- 1 || Kérd be a parancsokat (bekérő szöveg nélkül)! Írd ki, hány parancsot kapott a robot, és ebből hány volt érvénytelen, például: <code>Parancsok: 12, ebből érvénytelen: 1</code>
- 2 || Hol áll a robot az összes parancs végrehajtása után? Írd ki a szakasz számát: <code>Végpozíció: 3</code>
- 3 || Melyik volt a kiindulóponttól legtávolabbi szakasz, amelyre a robot eljutott, és hányadik parancs után érte el először? Az érvénytelen parancsokat is számold a sorszámozásnál. Írd ki a következő alakban: <code>Legtávolabbi szakasz: -4 (7. parancs után)</code> Ha a robot egyszer sem mozdult el, ezt írd ki: <code>A robot nem mozdult el.</code>
- 3 || Hányszor takarított a robot, és hány különböző szakaszt takarított ki? Írd ki a következő alakban: <code>Takarítások: 5, kitakarított szakaszok: 3</code>
- 2 || Hányszor lépett a robot a 0. szakaszra (lépés közben, a kiindulás nem számít bele)? Írd ki a következő alakban: <code>Visszatérések a 0. szakaszra: 2</code>
- 4 || A folyosó valójában csak a <b>-5. szakasztól az 5. szakaszig</b> tart. Ha a robot a folyosó végén álló szakaszról tovább lépne (előre az 5.-ről vagy hátra a -5.-ről), nekimegy a falnak: ilyenkor nem mozdul el, és ez egy ütközés. Ezekkel a szabályokkal ismét hajtsd végre az összes parancsot, és írd ki a végpozíciót és az ütközések számát, például: <code>Végpozíció: 5, ütközések: 2</code>
megoldas: |
  parancsok = input()

  print("1. feladat")
  ervenytelen = 0
  for p in parancsok:
      if p != "E" and p != "H" and p != "T":
          ervenytelen += 1
  print("Parancsok: " + str(len(parancsok)) + ", ebből érvénytelen: " + str(ervenytelen))

  print("2. feladat")
  hely = 0
  for p in parancsok:
      if p == "E":
          hely += 1
      elif p == "H":
          hely -= 1
  print("Végpozíció:", hely)

  print("3. feladat")
  hely = 0
  legtavolabb = 0
  mikor = 0
  for i in range(len(parancsok)):
      if parancsok[i] == "E":
          hely += 1
      elif parancsok[i] == "H":
          hely -= 1
      if abs(hely) > abs(legtavolabb):
          legtavolabb = hely
          mikor = i + 1
  if legtavolabb == 0:
      print("A robot nem mozdult el.")
  else:
      print("Legtávolabbi szakasz: " + str(legtavolabb) + " (" + str(mikor) + ". parancs után)")

  print("4. feladat")
  hely = 0
  takaritas = 0
  kitakaritott = []
  for p in parancsok:
      if p == "E":
          hely += 1
      elif p == "H":
          hely -= 1
      elif p == "T":
          takaritas += 1
          if hely not in kitakaritott:
              kitakaritott.append(hely)
  print("Takarítások: " + str(takaritas) + ", kitakarított szakaszok: " + str(len(kitakaritott)))

  print("5. feladat")
  hely = 0
  vissza = 0
  for p in parancsok:
      if p == "E" or p == "H":
          if p == "E":
              hely += 1
          else:
              hely -= 1
          if hely == 0:
              vissza += 1
  print("Visszatérések a 0. szakaszra:", vissza)

  print("6. feladat")
  hely = 0
  utkozes = 0
  for p in parancsok:
      if p == "E":
          if hely < 5:
              hely += 1
          else:
              utkozes += 1
      elif p == "H":
          if hely > -5:
              hely -= 1
          else:
              utkozes += 1
  print("Végpozíció: " + str(hely) + ", ütközések: " + str(utkozes))
